Recreating figure 3 requires the HZV029 plasma workflows, including the RP batch correction one. You will also need to have ran the HSV029 lipiodomics workflow and the HSV029 QC workflow.

The notebook uses two example mzML files, `batch5_MT_20210730_001.mzML` and `batch5_MT_20210730_003.mzML`, from the HZV029 dataset. They are not included in this repository to keep its size down; retrieve them from the HZV029 dataset and place them in this directory.
